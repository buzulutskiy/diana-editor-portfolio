# Архип Куинджи. Художник света

Учебный редакторский кейс Дианы Бузулуцкой: концепция современного переиздания монографии М. П. Неведомского об Архипе Куинджи.

Страница показывает редакционную идею, работу с историческим текстом, новую структуру и комментарии, иллюстрационную программу, три направления обложки, показательные развороты, параметры издания и производственный план-график.

- Живая страница: https://buzulutskiy.github.io/diana-editor-portfolio/
- Автор проекта: Диана Бузулуцкая, редактор — sneypova@yandex.ru, telegram @mkilljoym

## Как устроено

- `index.html` — вся страница: разметка, стили и скрипты в одном файле, без зависимостей и сборки.
- `assets/`, `public/project/` — фотографии обложек, развороты и разворот с содержанием (WebP).
- `public/fonts/` — Oranienbaum и Literata.

Открывается двойным кликом по `index.html` или с любого статического хостинга.

## Права

Монография Неведомского и произведения Архипа Куинджи находятся в общественном достоянии. Макеты, тексты и оформление кейса — Диана Бузулуцкая.
